## Installation

```bash
pip install -r requirements.txt
```

## Setup

```bash
# Set up environment variables
export SOCIAL_MEDIA_API_KEY="your_api_key"
export SOCIAL_MEDIA_API_SECRET="your_api_secret"
export REDIS_URL="redis://localhost:6379/0"
export DATABASE_URL="postgresql://user:password@localhost:5432/social_media"

# Run the server
uvicorn social_server:app --host 0.0.0.0 --port 8002 --workers 4
```

## Configuration

The social media module requires the following configuration:

```yaml
# config.yaml
social_media:
  api_key: "your_api_key"
  api_secret: "your_api_secret"
  platforms:
    - name: "Twitter"
      platform_type: "twitter"
      base_url: "https://api.twitter.com"
      rate_limit: 100
      timeout: 30
    - name: "LinkedIn"
      platform_type: "linkedin"
      base_url: "https://api.linkedin.com"
      rate_limit: 50
      timeout: 30
    - name: "Reddit"
      platform_type: "reddit"
      base_url: "https://api.reddit.com"
      rate_limit: 200
      timeout: 30
  campaigns:
    - name: "default"
      platform: "twitter"
      keywords: ["security", "vulnerability", "exploit"]
      monitoring_keywords: ["phishing", "malware", "scam"]
  intelligence:
    threat_types:
      - "phishing"
      - "malware"
      - "ransomware"
      - "scam"
      - "social_engineering"
      - "disinformation"
      - "coordination"
  scraping:
    default_time_range: "day"
    default_limit: 100
    rate_limit: 1000
    cache_duration: 3600
```

## API Documentation

### Endpoints

#### Platforms
- **POST** `/platforms` - Register a new social media platform
- **GET** `/platforms` - List all platforms
- **GET** `/platforms/{id}` - Get platform by ID
- **PUT** `/platforms/{id}` - Update platform
- **DELETE** `/platforms/{id}` - Delete platform

#### Content Scraping
- **POST** `/scrape` - Start content scraping for platform and keywords

#### Campaigns
- **POST** `/campaigns` - Create a new campaign
- **GET** `/campaigns` - List all campaigns
- **GET** `/campaigns/{id}` - Get campaign by ID
- **PUT** `/campaigns/{id}` - Update campaign
- **DELETE** `/campaigns/{id}` - Delete campaign

#### Intelligence
- **POST** `/intelligence/collect` - Collect threat intelligence
- **GET** `/intelligence` - List all intelligence
- **GET** `/intelligence/summary` - Get intelligence summary
- **POST** `/intelligence/analyze` - Analyze intelligence data

#### Trends
- **GET** `/trends` - Get trends data with optional platform and keywords

#### Health
- **GET** `/health` - Health check endpoint

### Data Models

#### SocialMediaPlatform
- `platform_id`: str - Unique identifier
- `name`: str - Platform name
- `platform_type`: str - Platform type (twitter, linkedin, etc.)
- `api_key`: str - API key
- `api_secret`: str - API secret
- `base_url`: str - Base API URL
- `rate_limit`: int - Rate limit
- `timeout`: int - Request timeout
- `enabled`: bool - Whether platform is enabled
- `metadata`: dict - Additional platform metadata

#### SocialMediaContent
- `content_id`: str - Unique identifier
- `platform`: str - Platform name
- `author`: str - Content author
- `text`: str - Content text
- `timestamp`: datetime - Content timestamp
- `url`: str - Content URL
- `engagement_metrics`: dict - Engagement metrics
- `metadata`: dict - Additional metadata
- `language`: str - Content language
- `sentiment`: str - Content sentiment
- `topics`: list - Content topics
- `entities`: list - Named entities

#### ThreatIntelligence
- `intelligence_id`: str - Unique identifier
- `source`: str - Intelligence source
- `threat_type`: str - Type of threat
- `severity`: str - Threat severity
- `confidence_score`: float - Confidence score
- `detected_at`: datetime - Detection timestamp
- `affected_platforms`: list - Affected platforms
- `indicators`: list - Threat indicators
- `remediation_actions`: list - Remediation actions
- `metadata`: dict - Additional metadata

#### SocialMediaCampaign
- `campaign_id`: str - Unique identifier
- `name`: str - Campaign name
- `platform`: str - Platform
- `campaign_type`: str - Campaign type
- `start_time`: datetime - Campaign start time
- `end_time`: datetime - Campaign end time
- `targets`: list - Campaign targets
- `keywords`: list - Campaign keywords
- `monitoring_keywords`: list - Monitoring keywords
- `status`: str - Campaign status
- `collected_intelligence`: list - Collected intelligence
- `metadata`: dict - Additional metadata
