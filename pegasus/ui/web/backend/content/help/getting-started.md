# Getting started

1. Install the desktop build or run the backend directly.
2. Open the console. The API gate asks for setup on first launch.
3. Attach a device and select it in the sidebar.
4. Run the health check in the Settings page.

## Where things live

- `~/.pegasus` - operator state, logs and the vault
- `log/events.jsonl` - the structured event log
- `pegasus/ui/web/backend` - the API surface
